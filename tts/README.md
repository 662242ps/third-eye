# Bundled Thai offline TTS

วางไฟล์เสียง TTS ที่มีสิทธิ์ใช้งานไว้ในโฟลเดอร์นี้ เพื่อให้โปรแกรมใช้ได้กับ
เครื่องอื่นโดยไม่ต้องติดตั้ง Thai Speech ใน Windows

## โมเดลที่ติดตั้งให้แล้ว

โปรเจกต์นี้มีโมเดล VachanaTTS ภาษาไทยใน `voices/th_f_2.onnx` พร้อมไฟล์
`speaker_config.json` โปรแกรมจะเรียกใช้งานผ่าน `vachanatts` แบบออฟไลน์และสร้าง
`alert_runtime.wav` ชั่วคราวทุกครั้งที่มีข้อความแจ้งเตือน

## ตัวเลือกเพิ่มเติม

1. `thai_tts.exe` — โปรแกรม TTS ที่รับพารามิเตอร์:

```text
thai_tts.exe --text "ข้อความภาษาไทย" --output "alert_runtime.wav"
```

2. Piper:

```text
piper.exe
thai_voice.onnx
thai_voice.onnx.json
```

Piper ต้องเป็นโมเดลภาษาไทยโดยเฉพาะ ห้ามใช้โมเดลภาษาอังกฤษ เพราะจะอ่านภาษาไทยผิด

## การแจกโปรแกรม

ต้องแจกไฟล์ executable, โมเดลเสียง และไฟล์ license ของโมเดลไปพร้อมกัน ตรวจสอบ
สิทธิ์การใช้งานโมเดลก่อนนำไปแจกหรือใช้เชิงพาณิชย์
