# Bundled Thai offline TTS

โฟลเดอร์นี้เก็บโมเดลสำหรับสร้างเสียง segment ล่วงหน้า โปรแกรมตรวจจับจริงใช้ไฟล์
WAV ใน `../assets/voice/segments/` จึงไม่ต้องโหลดโมเดลเสียงระหว่างเล่นวิดีโอ

## การทำงานปัจจุบัน

ไฟล์โมเดล VachanaTTS ใน `voices/` ใช้สำหรับสร้างไฟล์เสียงล่วงหน้าเท่านั้น ปัจจุบันมี
`th_m_1.onnx` พร้อม `speaker_config.json`

ขณะโปรแกรมตรวจจับวิดีโอจะไม่โหลด ONNX และไม่สร้างเสียงใหม่ทุกการแจ้งเตือน แต่จะต่อ
ไฟล์ WAV ที่สร้างไว้ใน `../assets/voice/segments/<voice_model>/` ทำให้ UI และวิดีโอไม่ถูกบล็อกจากงานสังเคราะห์เสียง

สร้างหรือสร้างไฟล์ segment ใหม่จากโฟลเดอร์โปรเจกต์ด้วย:

```powershell
python tools/generate_voice_segments.py
python tools/generate_voice_segments.py --voice-model th_m_1 --force
```

ต้องสร้าง segment ให้ครบสำหรับเสียงที่ต้องการเลือกในหน้าตั้งค่า หากไม่มีไฟล์ครบ โปรแกรมจะไม่สังเคราะห์เสียงใหม่ระหว่างตรวจจับ แต่จะใช้ไฟล์ cache หรือเสียงสำรองที่มีอยู่แทน เพื่อไม่ให้วิดีโอค้าง

## ตัวเลือก compatibility เพิ่มเติม

ตัวเลือกด้านล่างเป็น fallback สำหรับการติดตั้งแบบเก่า และจะไม่ถูกใช้ในโหมดปัจจุบัน
ที่ตั้งค่า `SEGMENT_VOICE_ONLY = True` เว้นแต่จะเปลี่ยน flag นี้ใน `vision/voice_alert.py`

1. `thai_tts.exe` — โปรแกรม TTS ที่รับพารามิเตอร์:

```text
thai_tts.exe --text "ข้อความภาษาไทย" --output "alert_runtime.wav"
```

2. Piper:

```text
piper.exe
thai_voice.onnx
thai_voice.onnx.json
```

Piper ต้องเป็นโมเดลภาษาไทยโดยเฉพาะ ห้ามใช้โมเดลภาษาอังกฤษ เพราะจะอ่านภาษาไทยผิด

## การแจกโปรแกรม

สำหรับการใช้งานตรวจจับปกติ ต้องแจกไฟล์ WAV ใน `assets/voice/segments/` และไฟล์
license ที่เกี่ยวข้อง หากต้องการให้ผู้ใช้สร้าง segment ใหม่บนเครื่องปลายทางจึงค่อยแจก
โมเดลใน `voices/` และ license ของโมเดลด้วย ตรวจสอบสิทธิ์ก่อนนำไปแจกหรือใช้เชิงพาณิชย์
